# *Data display*: show what matters

The Platform and the Manager are mostly numbers. Show the one that matters, big and in the serif; show the rest quietly.

## Card

The soft container for content: **14 px** radius, flat, color-led. Elevation comes from the field color, and a hairline when a white card sits on a white page.

<Demo surface="light" column code={`<Card title="Title" description="Supporting line">...</Card>
<Card tone="mint" title="On mint" />
<Card tone="teal" title="On teal" />
<Card bordered elevation="soft" />      // floats a little
<Card hover />                          // lifts on hover (clickable tiles only)`}>
  <div style={{display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(190px, 1fr))', gap: 12}}>
    <Card bordered title="Light" description="White with a hairline." />
    <Card tone="cloud" title="Cloud" description="A sunken well." />
    <Card tone="mint" title="Mint" description="A mint field." />
    <Card tone="teal" title="Teal" description="A dark field." />
    <Card tone="amber" title="Amber" description="A campaign field." />
    <Card bordered hover title="Hover me" description="A clickable tile lifts 5 px." />
  </div>
</Demo>

| Prop | Values | Notes |
| --- | --- | --- |
| `tone` | `light` `cloud` `mint` `amber` `teal` `aurora` `aurora-cool` `aurora-deep` | Aurora is for marketing and the Hub |
| `pad` | `sm` 16 \| `md` 20 \| default 28 | Product cards use `md` |
| `bordered` | boolean | A 1 px `border-light` |
| `elevation` | `soft` \| `float` | Only for floating tiles |
| `hover` | boolean | Only if the whole card is a link |

## Stat

A label, a **big serif figure**, an optional unit, a delta and a trend. One stat answers one question.

### Delta

The arrow shows **direction**; the color shows **whether it is good**. Fewer open cases is down and good, so it is green with a down arrow. A reader who cannot see color still reads the arrow, the sign and the (visually hidden) words "up" or "down".

<Demo surface="white">
  <Delta value={12} /><Delta value={-4} /><Delta value={-25} goodWhen="down" /><Delta value={0} />
</Demo>

## Charts

Bars and sparklines are drawn in SVG from the data palette, with the latest point in amber. Every chart has a **text label** (`aria-label`) listing its values, so it is readable without sight.

<Demo surface="white">
  <Card bordered title="Orders per week" description="From Toast, last 6 weeks">
    <div style={{marginTop: 12, overflowX: 'auto'}}><Bars data={[{label: 'W1', value: 412}, {label: 'W2', value: 438}, {label: 'W3', value: 401}, {label: 'W4', value: 466}, {label: 'W5', value: 490}, {label: 'W6', value: 512}]} /></div>
  </Card>
  <Sparkline label="Reviews trend" values={[4, 6, 5, 8, 7, 11, 13]} width={160} height={40} />
</Demo>

Rules: start the axis at zero for bars; label directly instead of a legend when there are two or fewer series; use at most six series (see [Colors](./colors#data-colors)).

## Table

A table is for comparing rows. Header cells are 12 px caps on a cloud band, rows have a hairline, **numbers right-aligned with tabular numerals**. Sorting is a button in the header with `aria-sort`.

On narrow screens a table becomes a list of cards, one per row, with the same labels. See [Patterns](./patterns).
