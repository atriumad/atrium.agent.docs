# *Surfaces*: one system, five rooms

One set of tokens and components, themed per room. A surface changes **roles** (what is the page, what is the card, what is the accent), never the components.

| | Platform | Manager | Hub | Mobile |
| --- | --- | --- | --- | --- |
| **For** | The restaurant owner | The agency team | The restaurant's guest | The owner on the go |
| **Theme** | Light | Charcoal chrome, cream work area | Light, per restaurant | Light |
| **Density** | Calm: 16 px body, roomy cards | Dense: 14 px, tables | Spacious, one task | Large targets, one decision |
| **Page** | `surface-page` cream | `surface-page` cream, charcoal side navigation | The restaurant's field | `surface-page` cream |
| **Accent** | Lime, once | Lime for the current page, clay for counts | The restaurant's color | Lime, once |
| **Figures** | Serif | Sans with tabular numerals in tables, serif in tiles | Serif | Serif |

## Platform

Calm and personal. A greeting with one italic phrase, the score leading, cards with room to breathe. The only filled card is the "Up next" call, in lime.

## Manager

Dense and fast. A charcoal side navigation, tables under a 3 px rule with a status in every row, and a **clay count** for the work waiting on a person. See the [portfolio pattern](./patterns#portfolio-table).

## Hub: a restaurant's own color

The Hub, the survey and public pages take each restaurant's **accent color and logo** on top of the same components. Two guards keep that safe:

1. **The accent replaces `--accent` only.** Text stays charcoal or cream; the accent never becomes text on cream.
2. **A contrast check at setup.** The accent must give 4.5:1 with its label color (the system picks charcoal or cream, whichever passes) and 3:1 against the page. If it fails, the system darkens it until it does and tells the account manager.

## Mobile

The owner checks in for a minute. One decision per screen, **44 px targets**, the figure that matters in the serif, push for what needs them. The same tokens, base type at 16 and more space.

## Agents

An agent appears wherever it acts or speaks: a face (Blobatar) and a name. Their colors predate this system and are their own identity, so they keep them for now. An agent never takes a status color, and a status never takes an agent's.

## Documentation

This site is the fifth room: cream and charcoal, a dark theme, the same tokens mapped onto Infima (see [Tokens](./tokens#in-this-site)). Headings carry the 3 px rule, tables sit under it, code uses JetBrains Mono.
