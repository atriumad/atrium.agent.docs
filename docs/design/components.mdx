## The contract

Every component meets the same rules. A component that cannot is not finished.

1. **It reads roles, not colors.** Only the tokens in [Colors](./colors), so a surface can re-theme it.
2. **It has every state.** Rest, hover, focus, active, disabled, and where it applies loading, error and selected.
3. **It is keyboard complete.** Reachable with Tab, operable with Enter and Space (and arrows for tabs and menus), with the focus ring from [Foundations](./foundations#focus).
4. **It is named for assistive technology.** A visible label, or an `aria-label` for icon-only parts. Errors are announced (`role="alert"`) and tied to the field.
5. **It never relies on color alone.** Status has a word and a mark.
6. **It respects reduced motion.** Durations are tokens that collapse to zero.
7. **Targets are large enough.** 44 px on mobile, 24 px at minimum on desktop.
8. **It has a loading, an empty and an error design** wherever it holds data.
