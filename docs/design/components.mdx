## The contract

Every component meets the same rules. A component that cannot is not finished.

1. **It reads roles, not colors.** Only the tokens in [Colors](./colors), so a surface can re-theme it.
2. **It is drawn, not shaded.** Hairlines, the 3 px rule and flat fills. A diffuse shadow only on a menu or a dialog.
3. **It is squared.** A 4 px radius for buttons and fields, 6 px for cards. Only chips are round.
4. **It has every state.** Rest, hover, focus, press, disabled, and where it applies loading, error and selected.
5. **It is keyboard complete**, with the 2 px clay focus ring.
6. **It is named for assistive technology.** A visible label, or an `aria-label` for icon-only parts. Errors are announced and tied to the field.
7. **It never relies on color alone.** Status has a word and a mark.
8. **It respects reduced motion.** Durations are tokens that collapse to zero.
9. **Targets are large enough.** 44 px on touch, 24 px at minimum on desktop.
10. **It has a loading, an empty and an error design** wherever it holds data.
