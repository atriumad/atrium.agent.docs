# *Colors*: three anchors and a warm accent

The brand is deep teal, mint, cloud and amber. The product adds a small set of **status** colors, because a dashboard has to say "good" and "wrong" and the brand palette has no red or green. Every value below lives in `src/design/tokens.ts`, and the CSS custom properties are generated from it.

## Using them

The default pairing is **two-tone**: mint on teal, or teal on mint. Amber is a third, rarer voice.

| Color | Share of a screen | Used for |
| --- | --- | --- |
| Cloud and white | About 70% | Page, cards, fields, tables |
| Deep teal | About 20% | Text, the dark chrome, the primary button |
| Mint | About 8% | Accent on dark, soft fills, selected rows |
| Amber | 2% or less | One highlight, one campaign field, the count badge |

## Status colors

The brand has no red and no green. These five are the **product layer**, taken from the Platform, Manager and Mobile prototypes. They are the only colors that carry a meaning.

  <StatusBadge status="neutral">Paused</StatusBadge>

:::caution Color never speaks alone
A status always has a word and a mark (an icon or a dot). A person who cannot tell terracotta from green must still read "Overdue" and see a cross. Text on a status tint always passes 4.5:1; see [Accessibility](./accessibility).
:::

Amber is **campaign**, not **warning**. A warning uses `status-warning` (an amber-ink on a pale amber tint), never an amber field.

## Data colors

## The dark theme

Dark is not an inversion. It is the Manager's chrome and any deep-teal surface: the roles are redefined, and the status colors lighten so they hold contrast on teal.

## Do and don't

<DoDontRow>
  <DoDont kind="do">
    Use teal-800 for text and mint-400 on teal. Both clear 7:1.
  </DoDont>
  <DoDont kind="dont">
    Use mint text on white, or amber text on anything. They fail contrast.
  </DoDont>
  <DoDont kind="do">
    Use <Highlight>one</Highlight> amber marker swipe behind the word that matters.
  </DoDont>
  <DoDont kind="dont">
    Use an amber field as an error. Amber is campaign; errors use the danger status.
  </DoDont>
</DoDontRow>
