# *Actions*: what you press

Everything you can press is a pill. One primary action per view; the rest are quieter.

| Variant | Use |
| --- | --- |
| `primary` | The one main action of a view. Teal with mint text (mint with teal text on dark) |
| `mint` | The main action on a teal field, or a friendly secondary on light |
| `amber` | A campaign call to action in marketing. Not for product actions |
| `outline` | A secondary action next to a primary |
| `ghost` | A tertiary action, and actions inside dense toolbars |
| `danger` | A destructive action, only after a confirmation (see Dialog) |

### API

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `variant` | `primary` \| `mint` \| `amber` \| `outline` \| `ghost` \| `danger` | `primary` | |
| `size` | `sm` \| `md` \| `lg` | `md` | `sm` 13 px, `md` 15 px, `lg` 17 px |
| `icon` / `iconRight` | `ReactNode` | none | Lucide at 16 px (`sm`, `md`) or 20 px (`lg`) |
| `iconOnly` | `boolean` | `false` | Needs `aria-label`. Square, 44 px on mobile |
| `loading` | `boolean` | `false` | Shows a spinner, sets `aria-busy`, disables the button, keeps its width |
| `block` | `boolean` | `false` | Full width. Use in dialogs and on mobile |
| `disabled` | `boolean` | `false` | 45% opacity. Explain why next to it; do not rely on the look |

### Anatomy and states

Label is 15 px, weight 600, `0.01em`, never wrapped. Padding is 12 by 24 px. **Hover** deepens the field one step. **Press** scales to 0.97. **Focus** shows the teal ring with the amber halo. **Loading** replaces the icon with a spinner and keeps the label.

<DoDontRow>
  <DoDont kind="do">Start the label with a verb: "Save client", "Resolve", "Send reply".</DoDont>
  <DoDont kind="dont">Use "OK", "Submit" or "Click here", or put two primary buttons side by side.</DoDont>
  <DoDont kind="do">Put the primary action last (right) in a group, and keep one per view.</DoDont>
  <DoDont kind="dont">Use `danger` for an action that is reversible. Use `outline` instead.</DoDont>
</DoDontRow>

## Link

A link in running text is deep teal (teal-500 is for secondary text only), underlined with a 3 px offset. On hover the underline darkens. A link that leaves the app says so.

## Chip

The stadium pill for filters, tags and choices. **Outlined** by default, a **filled** field when selected.

export const ChipDemo = () => {
  const [on, setOn] = useState('SEO');
  return (
    <>
      {['SEO', 'Marketing', 'Photography', 'Design'].map((c) => (
        <Chip key={c} onClick={() => setOn(c)} selected={on === c}>{c}</Chip>
      ))}
    </>
  );
};

A chip with `onClick` is a toggle button (`aria-pressed`). Without it, a chip is a label and is not focusable. A removable chip's close button is named "Remove".
