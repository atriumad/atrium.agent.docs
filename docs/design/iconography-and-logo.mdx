# *Iconography* and logo

Atrium's identity is typographic. It leans on the Greek **α** and a lowercase **atrium** wordmark, not on an icon set. Functional icons come from Lucide.

| Rule | Value |
| --- | --- |
| Colors | Deep teal on light, mint on deep teal. One color per mark |
| Clear space | Half the height of the mark on every side |
| Minimum size | 24 px tall for the mark, 80 px wide for the wordmark |
| Wordmark | Always lowercase: **atrium**. Use the SVG, never type it in a font |
| Recoloring | Via `currentColor` or a CSS mask, never a filter |

## Icons

Functional icons are **[Lucide](https://lucide.dev)**: a 24 px grid, **1.75 px stroke**, rounded caps and joins, which echoes the 1.5 px pill outlines. The brand ships no icon set of its own; when it does, it replaces Lucide behind the same names.

<IconGrid />

### Rules

- **Sizes.** 16 px beside 14 px text, 20 px in buttons and navigation, 24 px as a standalone mark. Never scale a Lucide icon by fractions.
- **Color.** Icons take `currentColor`. They are never a second accent color.
- **Meaning.** An icon never carries meaning alone. Pair it with a label, or give an icon-only button an `aria-label`. A status icon sits next to its word.
- **Set.** Add an icon to the list above before using it, so the product uses one vocabulary: one icon per concept.

## Agents

Each of the six agents has a face (a Blobatar generated from its name) and a pair of colors. They appear on the home page, in the footer and wherever an agent acts or speaks. See [Colors](./colors#agent-identities).

An agent is a **person-like presence**, so it never uses the mark, and it never wears a status color: the agent's colors are its identity, not its state.
