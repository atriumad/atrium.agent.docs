# *Forms*: label, control, hint, error

A form is a conversation. Ask for what you need, say why when it is not obvious, and when something is wrong say what to do.

## Field

The **field** wires the pieces together: a visible **label** above, the **control**, then a **hint** or an **error** underneath. The error replaces the hint, is announced (`role="alert"`) and is linked to the control with `aria-describedby`.

| State | Border | Notes |
| --- | --- | --- |
| Rest | `border-light` 1.5 px | White field, 8 px radius |
| Hover | `teal-500` | |
| Focus | `teal-800` + ring and halo | |
| Error | `status-danger-fg` | A message with an icon; never color alone |
| Disabled | none, cloud fill | Muted text; say why nearby |

Labels are 13 px, weight 600. Mark **optional** fields with "(optional)" and leave required ones unmarked: most fields are required.

## Checkbox, radio and switch

A **checkbox** is for a yes that is part of a form. A **radio** picks one of a few. A **switch** takes effect immediately, so it is for settings and never for a form that has a Save button.

## Rules

<DoDontRow>
  <DoDont kind="do">Validate when the person leaves the field, and again on submit. Keep what they typed.</DoDont>
  <DoDont kind="dont">Clear a form on error, or show errors before the person has had a chance to finish.</DoDont>
  <DoDont kind="do">Write the error as a fix: "Enter a full email, for example marco@casaolivo.com".</DoDont>
  <DoDont kind="dont">Write "Invalid input", and never put the label inside the field as a placeholder.</DoDont>
</DoDontRow>

- Use the **right control and keyboard**: `type="email"`, `inputmode="numeric"`, `autocomplete` tokens.
- Place **one column** of fields; put two side by side only when they are short and related (city and state).
- Disable the submit button only while saving (`loading`); never to say "the form is incomplete".
