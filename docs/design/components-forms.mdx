# *Forms*: label, control, hint, error

A field is squared, with a wide-caps label above it and a clay focus ring. Ask for what you need, say why when it is not obvious, and when something is wrong say what to do.

## Input

The **label** is the 11 px wide-caps label. The **hint** or the **error** sits underneath; the error replaces the hint, is announced (`role="alert"`) and is tied to the control with `aria-describedby`.

On a charcoal field the input is transparent with a lighter edge (`tone="dark"` in the system):

<Demo surface="dark">
  <div style={{width: '100%', maxWidth: 360}}><Input label="Email for the newsletter" placeholder="you@company.com" /></div>
</Demo>

| State | Edge | Notes |
| --- | --- | --- |
| Rest | `field-border` (charcoal-500), 1 px | Cream-100 fill, 4 px radius |
| Hover | charcoal-800 | |
| Focus | charcoal-800 and a 2 px clay outline | |
| Error | clay-500 | A message in clay-600 under the field; never color alone |
| Disabled | opacity 0.4 | Say why nearby |

:::note The field edge is charcoal-500
The system draws a field with the cream hairline. Cream-400 on a cream-100 field is 1.5:1, below the 3:1 a control edge needs, so the product uses `--field-border` (6.1:1). Cards and rules keep the hairline.
:::

Mark **optional** fields with "(optional)" and leave required ones unmarked.

## Checkbox, radio and switch

The **checkbox** is a squared 18 px box that fills lime with a charcoal tick (a CSS tick, not an icon). A **radio** picks one of a few and is round because the shape carries its meaning. A **switch** takes effect at once, so it is for settings and never for a form with a Save button.

<DoDontRow>
  <DoDont kind="do">Validate when the person leaves the field, and again on submit. Write the error as a fix.</DoDont>
  <DoDont kind="dont">Clear the form on error, write "Invalid input", or put the label inside the field as a placeholder.</DoDont>
</DoDontRow>

- Use the right control and keyboard: `type="email"`, `inputmode="numeric"`, `autocomplete` tokens.
- One column of fields; two side by side only when short and related.
- Disable submit only while saving (`loading`), never to say "incomplete".
