# *Formularios*: etiqueta, control, ayuda, error

Un campo es recto, con una etiqueta en mayúsculas espaciadas encima y un anillo de foco arcilla. Pide lo que necesitas, di por qué cuando no sea obvio, y cuando algo está mal di qué hacer.

## Input

La **etiqueta** es la etiqueta en mayúsculas espaciadas de 11 px. La **ayuda** o el **error** va debajo; el error reemplaza a la ayuda, se anuncia (`role="alert"`) y se liga al control con `aria-describedby`.

| Estado | Borde | Notas |
| --- | --- | --- |
| Reposo | `field-border` (charcoal-500), 1 px | Relleno cream-100, radio de 4 px |
| Hover | charcoal-800 | |
| Foco | charcoal-800 y un contorno arcilla de 2 px | |
| Error | clay-500 | Un mensaje en clay-600 bajo el campo; nunca solo color |
| Deshabilitado | opacidad 0.4 | Explica el porqué cerca |

:::note El borde del campo es charcoal-500
El sistema dibuja un campo con la línea fina crema. Cream-400 sobre un campo cream-100 es 1.5:1, por debajo del 3:1 que necesita el borde de un control, así que el producto usa `--field-border` (6.1:1). Las tarjetas y las reglas conservan la línea fina.
:::

Marca los campos **opcionales** con "(opcional)" y deja sin marca los obligatorios.

## Checkbox, radio e interruptor

El **checkbox** es una caja recta de 18 px que se rellena de lima con un tick carbón (un tick CSS, no un icono). Un **radio** elige uno entre pocos y es redondo porque la forma lleva su significado. Un **interruptor** surte efecto al instante, así que es para ajustes y nunca para un formulario con botón de Guardar.

  <DoDont kind="dont">Borrar el formulario ante un error, escribir "Entrada inválida", o poner la etiqueta dentro del campo como placeholder.</DoDont>

- Usa el control y el teclado correctos: `type="email"`, `inputmode="numeric"`, tokens de `autocomplete`.
- Una columna de campos; dos lado a lado solo cuando son cortos y relacionados.
- Deshabilita el envío solo mientras guarda (`loading`), nunca para decir "incompleto".
