# *Formularios*: etiqueta, control, ayuda, error

Un formulario es una conversación. Pide lo que necesitas, di por qué cuando no sea obvio, y cuando algo está mal di qué hacer.

## Campo

El **campo** une las piezas: una **etiqueta** visible arriba, el **control**, y debajo una **ayuda** o un **error**. El error reemplaza a la ayuda, se anuncia (`role="alert"`) y se liga al control con `aria-describedby`.

| Estado | Borde | Notas |
| --- | --- | --- |
| Reposo | `border-light` 1.5 px | Campo blanco, radio de 8 px |
| Hover | `teal-500` | |
| Foco | `teal-800` + anillo y halo | |
| Error | `status-danger-fg` | Un mensaje con icono; nunca solo color |
| Deshabilitado | ninguno, relleno cloud | Texto atenuado; explica el porqué cerca |

Las etiquetas son de 13 px, peso 600. Marca los campos **opcionales** con "(optional)" y deja sin marca los obligatorios: la mayoría lo son.

## Checkbox, radio e interruptor

Un **checkbox** es para un sí que forma parte de un formulario. Un **radio** elige uno entre pocos. Un **interruptor** surte efecto al instante, así que es para ajustes y nunca para un formulario con botón de Guardar.

## Reglas

<DoDontRow>
  <DoDont kind="do">Valida cuando la persona sale del campo, y otra vez al enviar. Conserva lo que escribió.</DoDont>
  <DoDont kind="dont">Borrar el formulario ante un error, o mostrar errores antes de que la persona termine.</DoDont>
  <DoDont kind="do">Escribe el error como una solución: "Escribe un correo completo, por ejemplo marco@casaolivo.com".</DoDont>
  <DoDont kind="dont">Escribir "Entrada inválida", y nunca poner la etiqueta dentro del campo como placeholder.</DoDont>
</DoDontRow>

- Usa el **control y el teclado correctos**: `type="email"`, `inputmode="numeric"`, tokens de `autocomplete`.
- Pon **una columna** de campos; pon dos lado a lado solo cuando son cortos y relacionados (ciudad y estado).
- Deshabilita el botón de enviar solo mientras guarda (`loading`); nunca para decir "el formulario está incompleto".
