# *Fundamentos*: las formas detrás de cada pantalla

## Espaciado

Una **grilla de 8 px** con medio paso de 4 px. El espacio entre cosas relacionadas es pequeño, el espacio entre grupos es grande. La marca respira: ante la duda, añade espacio.

<SpaceScale />

| Dónde | Separación |
| --- | --- |
| Icono a etiqueta | 4 a 8 px |
| Etiqueta a campo | 6 a 8 px |
| Entre campos | 16 px |
| Padding de tarjeta | 20 px en producto, 28 px en marketing |
| Entre tarjetas | 16 px |
| Entre secciones de página | 48 a 64 px |

## Layout

El contenido se detiene en **1200 px** (1360 para dashboards anchos). El margen lateral es `clamp(1.25rem, 4vw, 4rem)`. El Manager y la Platform muestran una navegación lateral desde `lg`; por debajo, la navegación pasa a un menú.

<Breakpoints />

Diseña primero para móvil. Una tabla que no cabe se vuelve una lista de tarjetas, nunca un scroll horizontal de la página.

## Radios

Píldoras para lo que se pulsa, tarjetas suaves para lo que se lee, de 4 a 8 px para los campos.

<RadiusScale />

## Bordes

Las píldoras y los contornos se dibujan con un trazo de **1.5 px**, nunca más grueso. Las líneas finas de tarjetas y tablas son de 1 px en `border-light`. Sobre oscuro, las líneas finas son `border-on-dark`.

## Elevación

La identidad es plana. La elevación es **color**: un campo menta o ámbar, una tarjeta blanca sobre una página cloud. Las sombras existen solo para lo que flota.

<ShadowScale />

| Usa una sombra para | No la uses para |
| --- | --- |
| Menús y popovers (`shadow-pop`) | Tarjetas en una cuadrícula |
| Diálogos, elevación al pasar el cursor (`shadow-float`) | Botones |
| Teselas bento sobre un campo aurora (`shadow-soft`) | Filas de tabla, inputs |

### Aurora y grano

Marketing y el Hub pueden usar la **aurora**: un lavado pálido de menta y ámbar desde las esquinas, con texto oscuro encima. Es secundaria y de bajo contraste. Las pantallas de producto no la usan.

## Movimiento

Las cosas se **asientan**. Un ease-out seguro, de unos 220 ms, sin rebote ni giro. El hover profundiza el campo un paso o lo sube a menta. Al pulsar, escala a 0.97 sin destello de color.

<MotionScale />

| Evento | Duración | Notas |
| --- | --- | --- |
| Pulsar | `dur-fast` 120 ms | Escala 0.97 |
| Hover, color, movimientos pequeños | `dur-base` 220 ms | |
| Paneles, diálogos, entradas | `dur-slow` 420 ms | Fundido y una subida corta |

Con `prefers-reduced-motion: reduce`, todas las duraciones bajan a 0 y la escala al pulsar a 1. El movimiento nunca lleva el significado por sí solo.

## Foco

El foco es un **anillo teal con un halo ámbar** (anillo menta sobre oscuro). El ámbar solo es 1.9:1 sobre blanco y no cumple; el anillo teal supera 3:1 en cada superficie, y el halo conserva la marca.
