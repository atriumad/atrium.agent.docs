# *Navegación*: saber dónde estás

## Tabs

Las tabs de filtro son **chips**, la única píldora: cambian vistas de la **misma** lista, con un conteo cuando ayuda. La tab seleccionada va rellena de carbón. Son un `tablist`.

export const TabsDemo = () => {
  const [v, setV] = useState('active');
  return <Tabs label="Estado" value={v} onChange={setV} items={[{id: 'active', label: 'Activos', count: 4}, {id: 'open', label: 'Abiertos', count: 3}, {id: 'contacted', label: 'Contactados', count: 1}, {id: 'resolved', label: 'Resueltos', count: 0}, {id: 'all', label: 'Todos', count: 4}]} />;
};

  items={[{id: 'active', label: 'Activos', count: 4}, ...]} />`}>
  <TabsDemo />
</Demo>

## Tabs subrayadas

Para **secciones de una página** (Resumen, Reseñas, Ajustes). Etiquetas en mayúsculas espaciadas sobre una línea fina; la actual lleva la regla de 3 px debajo.

export const UnderlineDemo = () => {
  const [v, setV] = useState('overview');
  return <div style={{width: '100%'}}><UnderlineTabs label="Secciones" value={v} onChange={setV} items={[{id: 'overview', label: 'Resumen'}, {id: 'reviews', label: 'Reseñas'}, {id: 'settings', label: 'Ajustes'}]} /></div>;
};

<Demo surface="white"><UnderlineDemo /></Demo>

## Control segmentado

Un interruptor pequeño entre **dos y cuatro opciones** que cambian cómo se muestran los mismos datos (un rango, una vista). Un grupo recto de tinta de 1 px con `aria-pressed`, no tabs.

export const SegDemo = () => {
  const [v, setV] = useState('30d');
  return <Segmented label="Rango" value={v} onChange={setV} items={[{id: '7d', label: '7 días'}, {id: '30d', label: '30 días'}, {id: '90d', label: '90 días'}]} />;
};

<Demo surface="white"><SegDemo /></Demo>

## Migas de pan

La ruta en una zona profunda, como etiquetas en mayúsculas espaciadas. El último elemento es la página actual, no un enlace.

## Paginación

Para listas largas donde la persona busca una fila. Prefiere primero filtros y búsqueda.

export const PagerDemo = () => {
  const [p, setP] = useState(2);
  return <Pager pages={5} page={p} onChange={setP} />;
};

## Navegación lateral y barra superior

El chrome del Manager: una navegación lateral **carbón** con el wordmark tipográfico, la página actual en lima con un borde lima de 3 px, títulos de grupo como etiquetas en mayúsculas espaciadas y un **conteo arcilla** para el trabajo que espera a una persona. La barra superior lleva la búsqueda y a la persona. Por debajo de `lg`, la navegación lateral pasa a un botón de menú.

<Demo surface="light">
  <ShellPattern />
</Demo>

| Parte | Regla |
| --- | --- |
| Página actual | `aria-current="page"`, texto lima y un borde lima de 3 px |
| Insignia de conteo | Arcilla, solo para trabajo que espera a una persona, oculta en cero |
| Grupos | Como máximo cuatro, con un título en mayúsculas espaciadas |
| Etiquetas | Una o dos palabras, sustantivos: "Casos", "Aprobaciones" |
