# *Acciones*: lo que se pulsa

Todo lo que se puede pulsar es una píldora. Una acción primaria por vista; las demás son más discretas.

| Variante | Uso |
| --- | --- |
| `primary` | La acción principal de una vista. Teal con texto menta (menta con texto teal sobre oscuro) |
| `mint` | La acción principal sobre un campo teal, o una secundaria amable sobre claro |
| `amber` | Una llamada a la acción de campaña en marketing. No para acciones del producto |
| `outline` | Una acción secundaria junto a una primaria |
| `ghost` | Una acción terciaria, y acciones dentro de barras de herramientas densas |
| `danger` | Una acción destructiva, solo después de una confirmación (ver Diálogo) |

### API

| Prop | Tipo | Por defecto | Notas |
| --- | --- | --- | --- |
| `variant` | `primary` \| `mint` \| `amber` \| `outline` \| `ghost` \| `danger` | `primary` | |
| `size` | `sm` \| `md` \| `lg` | `md` | `sm` 13 px, `md` 15 px, `lg` 17 px |
| `icon` / `iconRight` | `ReactNode` | ninguno | Lucide a 16 px (`sm`, `md`) o 20 px (`lg`) |
| `iconOnly` | `boolean` | `false` | Necesita `aria-label`. Cuadrado, 44 px en móvil |
| `loading` | `boolean` | `false` | Muestra un spinner, pone `aria-busy`, deshabilita el botón, conserva su ancho |
| `block` | `boolean` | `false` | Ancho completo. Úsalo en diálogos y en móvil |
| `disabled` | `boolean` | `false` | 45% de opacidad. Explica el porqué al lado; no dependas del aspecto |

### Anatomía y estados

La etiqueta es de 15 px, peso 600, `0.01em`, sin saltos de línea. El padding es de 12 por 24 px. El **hover** profundiza el campo un paso. Al **pulsar** escala a 0.97. El **foco** muestra el anillo teal con el halo ámbar. **Cargando** reemplaza el icono por un spinner y conserva la etiqueta.

## Enlace

Un enlace en texto corrido es teal profundo (teal-500 es solo para texto secundario), subrayado con 3 px de separación. Al pasar el cursor el subrayado se oscurece. Un enlace que sale de la app lo dice.

## Chip

La píldora estadio para filtros, etiquetas y opciones. **Con contorno** por defecto, un campo **relleno** cuando está seleccionado.

export const ChipDemo = () => {
  const [on, setOn] = useState('SEO');
  return (
    <>
      {['SEO', 'Marketing', 'Fotografía', 'Diseño'].map((c) => (
        <Chip key={c} onClick={() => setOn(c)} selected={on === c}>{c}</Chip>
      ))}
    </>
  );
};

Un chip con `onClick` es un botón de alternancia (`aria-pressed`). Sin él, un chip es una etiqueta y no recibe foco. El botón de cerrar de un chip removible se llama "Remove".
