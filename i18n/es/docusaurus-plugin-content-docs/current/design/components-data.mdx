# *Visualización de datos*: muestra lo que importa

La Platform y el Manager son sobre todo números. Muestra el que importa, grande y en la serif; muestra el resto en voz baja.

## Tarjeta

El contenedor suave del contenido: radio de **14 px**, plana, guiada por el color. La elevación viene del color del campo, y de una línea fina cuando una tarjeta blanca está sobre una página blanca.

<Demo surface="light" column code={`<Card title="Título" description="Línea de apoyo">...</Card>
<Card tone="mint" title="Sobre menta" />
<Card tone="teal" title="Sobre teal" />
<Card bordered elevation="soft" />      // flota un poco
<Card hover />                          // sube al pasar el cursor (solo tesela clicable)`}>
  <div style={{display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(190px, 1fr))', gap: 12}}>
    <Card bordered title="Claro" description="Blanco con una línea fina." />
    <Card tone="cloud" title="Cloud" description="Un hueco hundido." />
    <Card tone="mint" title="Menta" description="Un campo menta." />
    <Card tone="teal" title="Teal" description="Un campo oscuro." />
    <Card tone="amber" title="Ámbar" description="Un campo de campaña." />
    <Card bordered hover title="Pasa el cursor" description="Una tesela clicable sube 5 px." />
  </div>
</Demo>

| Prop | Valores | Notas |
| --- | --- | --- |
| `tone` | `light` `cloud` `mint` `amber` `teal` `aurora` `aurora-cool` `aurora-deep` | La aurora es para marketing y el Hub |
| `pad` | `sm` 16 \| `md` 20 \| por defecto 28 | Las tarjetas de producto usan `md` |
| `bordered` | boolean | Una línea de 1 px `border-light` |
| `elevation` | `soft` \| `float` | Solo para teselas que flotan |
| `hover` | boolean | Solo si toda la tarjeta es un enlace |

### Delta

La flecha muestra la **dirección**; el color muestra **si es bueno**. Menos casos abiertos es hacia abajo y bueno, así que va en verde con una flecha hacia abajo. Quien no ve el color igual lee la flecha, el signo y las palabras (ocultas a la vista) "up" o "down".

  <Delta value={12} /><Delta value={-4} /><Delta value={-25} goodWhen="down" /><Delta value={0} />
</Demo>

## Gráficos

Las barras y las sparklines se dibujan en SVG con la paleta de datos, con el último punto en ámbar. Todo gráfico tiene una **etiqueta de texto** (`aria-label`) con sus valores, para que se pueda leer sin vista.

<Demo surface="white">
  <Card bordered title="Pedidos por semana" description="De Toast, últimas 6 semanas">
    <div style={{marginTop: 12, overflowX: 'auto'}}><Bars data={[{label: 'S1', value: 412}, {label: 'S2', value: 438}, {label: 'S3', value: 401}, {label: 'S4', value: 466}, {label: 'S5', value: 490}, {label: 'S6', value: 512}]} /></div>
  </Card>
  <Sparkline label="Tendencia de reseñas" values={[4, 6, 5, 8, 7, 11, 13]} width={160} height={40} />
</Demo>

Reglas: empieza el eje en cero en las barras; etiqueta directamente en lugar de una leyenda cuando hay dos series o menos; usa como máximo seis series (ver [Colores](./colors#colores-de-datos)).

## Tabla

Una tabla sirve para comparar filas. Las celdas de cabecera son mayúsculas de 12 px sobre una banda cloud, las filas llevan una línea fina, **los números alineados a la derecha con numerales tabulares**. Ordenar es un botón en la cabecera con `aria-sort`.

<Demo surface="white" column>

  ]} />
</Demo>

En pantallas estrechas una tabla se vuelve una lista de tarjetas, una por fila, con las mismas etiquetas. Ver [Patrones](./patterns).
