# *Colores*: tres anclas y un acento cálido

La marca es teal profundo, menta, cloud y ámbar. El producto añade un conjunto pequeño de colores de **estado**, porque un dashboard tiene que decir "bien" y "mal" y la paleta de la marca no tiene rojo ni verde. Cada valor de abajo vive en `src/design/tokens.ts`, y las propiedades CSS se generan desde ahí.

## La paleta de la marca

## Cómo usarlos

La combinación por defecto es **de dos tonos**: menta sobre teal, o teal sobre menta. El ámbar es una tercera voz, más rara.

| Color | Parte de una pantalla | Se usa para |
| --- | --- | --- |
| Cloud y blanco | Cerca del 70% | Página, tarjetas, campos, tablas |
| Teal profundo | Cerca del 20% | Texto, el chrome oscuro, el botón primario |
| Menta | Cerca del 8% | Acento sobre oscuro, rellenos suaves, filas seleccionadas |
| Ámbar | 2% o menos | Un resaltado, un campo de campaña, la insignia de conteo |

## Colores de estado

La marca no tiene rojo ni verde. Estos cinco son la **capa de producto**, tomados de los prototipos de Platform, Manager y Mobile. Son los únicos colores que llevan un significado.

:::caution El color nunca habla solo
Un estado siempre tiene una palabra y una marca (un icono o un punto). Quien no distingue terracota de verde debe poder leer "Vencido" y ver una cruz. El texto sobre un tinte de estado siempre pasa 4.5:1; ver [Accesibilidad](./accessibility).
:::

El ámbar es **campaña**, no **aviso**. Un aviso usa `status-warning` (una tinta ámbar sobre un tinte ámbar pálido), nunca un campo ámbar.

## Colores de datos

Para gráficos, en el orden en que se usan las series. Seis es el límite: más que eso, agrupa o usa múltiplos pequeños. Las series adyacentes no dependen solo del tono, así que los gráficos también usan posición, etiquetas o anotación directa.

## El tema oscuro

Oscuro no es una inversión. Es el chrome del Manager y cualquier superficie teal profundo: se redefinen los roles y los colores de estado se aclaran para mantener el contraste sobre teal.

## Haz y no hagas

<DoDontRow>
  <DoDont kind="do">
    Usa teal-800 para el texto y mint-400 sobre teal. Los dos superan 7:1.
  </DoDont>
  <DoDont kind="dont">
    Usar texto menta sobre blanco, o texto ámbar sobre cualquier cosa. No cumplen el contraste.
  </DoDont>
  <DoDont kind="do">
    Usa <Highlight>un</Highlight> trazo de marcador ámbar detrás de la palabra que importa.
  </DoDont>
  <DoDont kind="dont">
    Usar un campo ámbar como error. El ámbar es campaña; los errores usan el estado de peligro.
  </DoDont>
</DoDontRow>
