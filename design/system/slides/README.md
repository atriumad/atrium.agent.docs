# Slide system — Atrium AD

Seven slide archetypes, each a standalone 1280×720 HTML file. They exist to show
how the brand behaves at presentation scale; copy them into a deck shell as needed.

| File | Use |
|---|---|
| `TitleSlide.html` | Deck opener — ink field, wordmark top-left, date rail |
| `SectionSlide.html` | Lime divider with an oversized Bodoni section number |
| `StatementSlide.html` | One sentence with the italic emphasis swap |
| `StatsSlide.html` | Four Bodoni figures on ink |
| `ComparisonSlide.html` | Two ruled columns; the recommendation is the lime card |
| `QuoteSlide.html` | Full-bleed clay, serif italic testimonial |
| `WorkSlide.html` | Three-up image grid with caps captions |
| `ClosingSlide.html` | Oversized wordmark and contact rail |

Rules: one lime or clay field per deck spread, never two in a row. Every slide
carries either the wordmark or a caps client label, never both in the same corner.
Body copy on a slide never goes below 20px.
