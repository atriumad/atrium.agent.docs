Use `Button` for every action; it is the only button in the system.

```jsx
<Button variant="lime" size="lg">See the work</Button>
<Button variant="outline">Read the case study</Button>
```

Variants: `primary` (ink fill — the default CTA), `lime` (the loud signal, one per view),
`clay` (warm secondary), `outline`, `ghost`. Sizes `sm | md | lg`. Hover deepens the fill
one step; `outline` inverts to a solid ink fill. Never round a button to a pill — chips are
the only pill shape in ATRIUM AD.
